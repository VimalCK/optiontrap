# Landing page showcase images

Drop the product screenshots here with these exact filenames. They are shown
in the auto-rotating showcase carousel on the login/landing page
(`src/pages/Login.tsx` → `SHOTS`).

- `oi-history.png`  — OI Price History chart (per-strike CE/PE OI + price)
- `pnl-journal.png` — Paper trading Trade Journal (stats, heatmap, trade log)

Recommended: wide screenshots (~1024×512, roughly 2:1). PNG or JPG both work
(update the extension in `SHOTS` if you use `.jpg`).
